# Railway Resilience During Large-Scale Events
## 1. Overview

This project investigates how the Dutch railway network responds to increased passenger demand during large-scale events.  
The analysis compares passenger volumes, train services and delays on event days with comparable non-event days.  
One case is studied: **King’s Day 2024**.

**Main research question:**  
> How does the Dutch railway network respond to increased passenger demand during large-scale events, in terms of passenger volumes, train services and punctuality?
